## 残っていること

1. **トレーナーがクライアントの記録をその場で直す**（追加予定。方針の「爆速インライン編集」）。今回の自動保存・元に戻すの仕組みを使える。着手時に、代理入力を含むか・権限・入力者の表示を決める。
2. **iOS の次のビルド**（master に未リリースの変更が溜まっている: ログイン画面の整理、有酸素、それ以前の分）。合わせてログイン用リンクの第2段階:
   - リンクで作ったアカウントは、今はアプリにログインできない（Apple・Google・メールが無い）。当面は Web（ホーム画面に追加）で使ってもらう。
   - Universal Links（auxlog.app の apple-app-site-association とアプリの associatedDomains）とアプリ側の /join 受け口。
   - アプリへの誘導の形はオーナー了承済み: Universal Links は未インストールだと App Store を開かず Web が開く。「ようこそ」の画面に「このまま始める（ブラウザ）」「アプリで始める（App Store → 入れたらもう一度リンクを押す）」。遅延ディープリンクはやらない。先にブラウザで始めた人は、ブラウザの画面の「アプリで開く」でその場でアプリ用の使い捨てリンクを作って移る。
   - LINE から開いた時にアプリが直接開くかは実機で要確認（今はいつものブラウザで開く設定）。
   - アプリの古い画面: 招待コードの入力（src/app/invite.tsx）を案内に、設定のアカウント（account.tsx）で仮のメールを出さない。
3. **後から自分の Apple・Google・メールを登録**して、トレーナーに頼らず機種変更できるようにする。その時、トレーナーが契約中のクライアントのログイン用リンクを作れる（＝クライアントとしてログインできる）扱いを決め直す。
4. メニューのインポートの小さな残り: .xls 非対応、ストレッチの種目が無い（「対応できなかった種目」になる）、同じ表で同じ名前の種目（重量ありと自重の「スクワット」など）は1つの対応にまとまる。
5. セルフモードのプログラム生成の統一（優先度は低め）。
6. 保留中（メモリより）: 週の早送りの警告ポップアップ（設計は合意済み）、自由記録モード、レビュー依頼のポップアップ。

## 注意（今回わかったこと）

- **コミットの前に `git status` でステージ済みのファイルを確かめる。** ~/dev/auxlog は複数のチャットが同じフォルダで並行して作業している。10/28 に別のチャットのステージ済みの変更をまとめてコミット・push してしまった（285557c、オーナーは了承済み）。自分のファイルだけを git add し、`git diff --cached --stat` で確かめてからコミットする。
