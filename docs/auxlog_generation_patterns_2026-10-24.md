# Auxlogで作成：生成されるプログラムの一覧（固定テンプレート方式）

作成日: 2026-10-24（本番の種目マスタ・週次パラメータで、lib/coaching/base_templates.ts と generateFromBaseTemplate を実行した結果）

## 前提

- 週の日数ごとに1つのベーステンプレート（週2〜7日の6つ）。時間（〜60分 / 60〜90分 / 90分〜）で、種目ごとの「何分コースから含めるか」に従って絞る。
- 重点部位を選ぶと、その部位の種目は〜60分でも残し、対象の日の枠を差し替えて種目を増やす（後半の「重点部位を選んだ時」）。
- セット数は代表として **9週間の Week 1** の値（ウォームアップを除く）。週数で変わるのは強度・セット数の流れだけで、種目は変わらない。
- 部位の「脚」にはふくらはぎを含む。体幹はその日の最後に並ぶ。

### 2つ選んだ場合

- 選んだ順に、上の差し替えをそれぞれ行う。同じ枠は2回差し替えない。
- もう一方の重点部位の種目は奪わない（例：胸＋三頭なら、三頭の枠は胸に奪われない）。
- 同じ枠を取り合う組み合わせ（脚＋体幹はどちらもふくらはぎの枠）は、先に選んだ方だけ差し替わり、後の方は既存の種目が〜60分でも残るだけになる。
