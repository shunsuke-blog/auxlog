# Auxlogで作成：プログラム生成のルール（固定テンプレート方式）

作成日: 2026-10-24（今のコードと本番DBの設定値から書き起こしたもの）

トレーナー画面の「Auxlogで作成」が、どういう決まりでプログラムを作っているかをまとめたものです。2026-10-24 に、条件から種目を割り振る動的な方式をやめ、**プロが組んだ分割法を骨組み（ベーステンプレート）として固定し、入力に応じて絞り込む方式**に切り替えました。

- 実際の生成結果の一覧: [auxlog_generation_patterns_2026-10-24.md](auxlog_generation_patterns_2026-10-24.md)
- セルフモード（トレーニーが自分で使う9週間プログラム）は、まだ以前の動的な方式のまま。後から同じ方式に移す予定。

---

## 1. 入力と流れ

| 入力 | 選べる値 | 何に効くか |
|---|---|---|
| 週の日数 | 2〜7日 | 使うベーステンプレート（3章） |
| 1回の時間 | 〜60分 / 60〜90分 / 90分〜 | 入れる種目（4章） |
| 特に鍛える部位 | なし、または 胸・背中・肩・二頭・三頭・脚・体幹 から最大2つ | 種目の保護と差し替え（5章） |
| 週数 | 1〜16週 | 週ごとの強度・セット数の流れ（8章）。種目は変わらない |

生成の流れ:

1. 週の日数のベーステンプレートを選ぶ。
2. 重点部位の差し替えと保護をする（5章）。
3. 時間で種目を絞る（4章）。体幹はその日の最後に並べる。
4. 週数から各週に使う元の週（W1〜W9）を決め（8章）、DB の週ごとの値でセット・回数・重量・努力度を入れる（7章）。

---

## 2. 基本の考え方

- テンプレートは**枠組みだけ**を持つ（どの種目を、どの順に、何分コースから入れるか）。重量・強度・セット数・回数の範囲は持たず、生成時に DB の週ごとの値を入れる。
- 筋肉の連動を崩さない（改定ルール①）。三頭は押す日、二頭は引く日、体幹は脚の日に置き、体幹はその日の最後にする。テンプレートがこれを満たしていることはテストで確認している（週7日のリカバリーの日だけは、腕のパンプを押す・引く種目なしで入れる）。
- 種目は種目マスタの**一意のキー（code）**で指定する（6章）。

---

## 3. ベーステンプレート

| 週の日数 | 分割法 | Day の構成 |
|---|---|---|
| 週2日 | 全身 A / B | 全身 A（胸・前モモ・背中水平・三頭・腹筋）、全身 B（裏モモ・肩・背中垂直・二頭・カーフ） |
| 週3日 | 全身 A / B / C | 全身 A・B（週2日と同じ）、全身 C（レッグプレス・胸フライ・背中・腕・腹筋）。脚の主役を日ごとに替える（スクワット → デッドリフト → レッグプレス） |
| 週4日 | Upper / Lower × 2 | Upper A、Lower A、Upper B、Lower B |
| 週5日 | Upper / Lower / Push / Pull / Legs | Upper、Lower（週4日の Lower A と同じ）、Push、Pull、Legs |
| 週6日 | Push / Pull / Legs × 2 | Push A（胸メイン）、Pull A（背中垂直メイン）、Legs A（四頭メイン）、Push B（肩メイン）、Pull B（背中水平メイン）、Legs B（ハムメイン） |
| 週7日 | Push / Pull / Legs × 2 ＋ リカバリー | 週6日と同じ6日 ＋ Active Recovery（体幹・カーフ・腕のパンプ） |

各 Day の種目・並び順・含める時間は、一覧ファイルの「2. 各テンプレートの中身」を参照。元データはオーナー作成の「AUXLOG Base Templates」（週2〜4日）と「週5~7.ts」。

---

## 4. 時間による絞り込み

- テンプレートの種目ごとに「何分コースから含めるか」（60 / 75 / 90）を持つ。選んだ時間以下の種目だけを入れる。
  - 60 … 〜60分でも入れる（メイン種目など）
  - 75 … 60〜90分以上で入れる
  - 90 … 90分〜だけ入れる
- 配列の後ろから削る方式ではないので、「実施する順」と「残す優先順位」は別に決められる（例：体幹は最後に行うが、〜60分でも残す）。
- 1日の種目数の上限（以前の改定ルール②：5 / 7 / 9種目）は使わない。テンプレートの含める時間で決まる。

---

## 5. 重点部位（改定ルール③）

### 5-1. 保護（Priority Override）

選んだ部位の種目は、含める時間を 60 に上書きする。〜60分を選んでも、その部位の種目は削られない。差し替えで入れた種目も 60 にする。

### 5-2. 差し替え（Slot Swap）

対象の日にある「奪う枠」を、重点部位の種目に置き換えて、その部位の種目数を増やす。

| 重点部位 | 対象の日 | 奪う枠 | 差し替え後（先頭から、その日にまだ無い種目） |
|---|---|---|---|
| 胸 | Upper・Push・全身 | 三頭 | ペックデックフライ → ダンベルフライ |
| 背中 | Upper・Pull・全身 | 二頭 | ストレートアームプルダウン → シーテッドケーブルロウ |
| 肩 | Upper・全身 | 三頭（無ければ二頭） | サイドレイズ → ケーブルサイドレイズ → インクラインサイドレイズ |
| 二頭 | Upper・Pull・全身 | 肩の後部 | ハンマーカール → ケーブルカール |
| 三頭 | Upper・Push・全身 | 肩の後部 | ケーブルトライセプスエクステンション → スカルクラッシャー |
| 脚 | Lower・Legs・全身 | ふくらはぎ | デッドリフトの日はレッグエクステンション → レッグカール、それ以外の日はレッグカール → レッグエクステンション |
| 体幹 | Lower・Legs・全身 | ふくらはぎ | ケーブルクランチ → ハンギングニーレイズ → レッグレイズ |

- 全身の日（週2・3日）は、どの部位でも対象。リカバリーの日（週7日の Day7）は対象外。
- 対象の日に奪う枠が無ければ、その日は差し替えない（例：週4日の胸は、三頭がある Upper A だけ）。
- ケーブルプルオーバーは種目マスタに無いため、同じ動きのストレートアームプルダウンを使う。
- 肩は前部を押す種目で十分使うため、側部の種目を足す。

### 5-3. 2つ選んだ時

- 選んだ順に差し替える。同じ枠は2回差し替えない。
- もう一方の重点部位の種目は奪わない（例：胸＋三頭なら、三頭の枠は胸に奪われない）。ただし、自分の部位の枠は使ってよい（脚を選んだ時のふくらはぎ）。
- 同じ枠を取り合う組み合わせ（脚＋体幹はどちらもふくらはぎ）は、先に選んだ方だけ差し替わる。後の方は、既存の種目が〜60分でも残るだけ。

## 6. 種目の指定

- テンプレートは種目マスタの `exercise_master.code`（例：`barbell_bench_press`）で種目を指定する。名前を直してもテンプレートは壊れない。テンプレートと差し替え先のキーがすべてマスタにあることはテストで確認している。
- 1RM管理（重量を%で出す）かどうかは種目マスタの登録で決まる。ただしテンプレートで「1RM管理しない」と指定した種目は、補助種目として扱う（週5〜7日のダンベルショルダープレス）。
- テンプレートの指定がマスタに無かった種目の扱い:

| テンプレートの指定 | 使っている種目 |
|---|---|
| barbell_squat | ローバースクワット（オーナー決定） |
| overhead_triceps_extension | トライセプスオーバーヘッドエクステンション（同じ種目、キーの表記違い） |
| hanging_leg_raise（週7日 Day7） | ハンギングニーレイズ（マスタに無いため代用） |
| cable_kickback（週7日 Day7） | ケーブルトライセプスエクステンション（マスタに無いため代用） |

## 7. セット・回数・重量・努力度（DB の週ごとの値を入れる）

### 7-1. 1RM管理の種目（重量を%で出す）

種目の動き（胸プレス・肩プレス・スクワット・ヒップヒンジ）ごとの値（movement_pattern_weekly_params）を使う。

- 1セット目（トップセット）：その週の %1RM × 回数。RIR は「10 − RPE」。ボリューム期は RPE 9（RIR1）を上限にする。
  - 週の日数による補正：週2日は %1RM +4%、週3日は +2%、週4〜7日は ±0。
- 2セット目以降（バックオフ）：トップの重量 × 設定の割合 × 設定の回数 × 設定のセット数、RIR2。
- 同じ動きの種目が週に2回ある場合（例：週4日のローバースクワットとハイバースクワット）は、どちらも同じ値になる（オーナー決定：別の値にしない）。

### 7-2. それ以外の種目（重量は空欄＝前回の記録から提案）

テンプレートの枠ごとに対応する DB の枠（program_weekly_params）の値を使う。

- セット数：その週の DB の値（時間では増減しない。時間の違いは種目の数に出る）。
- 回数：回数の範囲の下限を入れ、コメントに「◯〜◯回の範囲で」と書く。
- 努力度：RIR ＝ 10 − その週の RPE。

### 7-3. 特別な週・日

- **MaxOut 週（最終週）**：1RM管理の種目だけを残す。トップセットは回数1を入れ、「できる限り多くの回数に挑戦」とコメントする。
- **MaxOut の直前の回復週（元のW8）**：重量は保ち、セット数と努力度を下げる週（2026-10-24 にDBの値を修正）。
  - メイン種目のトップセット：%1RM はそのまま、回数を2回減らして RPE 7（例：胸プレス 86%×2）。バックオフは2セット。
  - 補助種目：RPE 7.5（RIR3）、W7 より少ないセット数。
- **途中の回復週**（10週以上のプランで、MaxOut の直前以外に入る回復週）：直前の週より重量を約1割下げ（%1RM × 0.9）、セット数を約6割（バックオフは2セット）、全セット RIR3。
- **リカバリーの日（週7日の Day7）**：全セットの RIR を +1 する。

## 8. 週の並び（週数ごと）

元の9週間プログラムは、ボリューム期4週（W1〜4）→ 強度期3週（W5〜7）→ 回復週（W8）→ MaxOut（W9）。N週のプログラムは、各週に元の9週間のどの週の値を使うかを次の決まりで割り当てる。

1. 4週以上なら最終週を MaxOut（W9）、6週以上ならその前を回復週（W8）にする。
2. 残りの負荷の高い週が7週を超えて続く時は、途中に回復週を入れる（必要な最小の数、区間はなるべく均等）。
3. 負荷の高い週の前半をボリューム期（元のW1〜4）、後半を強度期（元のW5〜7）にする（おおむね4：3）。

| 週数 | 各週に使う元の週（V＝ボリューム期、I＝強度期、D＝回復週、M＝MaxOut） |
|---|---|
| 1週 | V1 |
| 2週 | V1 I5 |
| 3週 | V1 V4 I5 |
| 4週 | V1 V4 I5 M9 |
| 5週 | V1 V4 I5 I7 M9 |
| 6週 | V1 V4 I5 I7 D8 M9 |
| 7週 | V1 V3 V4 I5 I7 D8 M9 |
| 8週 | V1 V3 V4 I5 I6 I7 D8 M9 |
| 9週 | V1 V2 V3 V4 I5 I6 I7 D8 M9（セルフモードと同じ） |
| 10週 | V1 V2 V3 V4 D8 I5 I6 I7 D8 M9 |
| 11週 | V1 V2 V3 V3 D8 V4 I5 I6 I7 D8 M9 |
| 12週 | V1 V2 V3 V3 V4 D8 I5 I6 I6 I7 D8 M9 |
| 13週 | V1 V2 V2 V3 V3 D8 V4 I5 I6 I6 I7 D8 M9 |
| 14週 | V1 V2 V2 V3 V3 V4 D8 I5 I6 I6 I7 I7 D8 M9 |
| 15週 | V1 V2 V2 V3 V3 V4 D8 V4 I5 I6 I6 I7 I7 D8 M9 |
| 16週 | V1 V2 V2 V3 V3 V4 V4 D8 I5 I5 I6 I6 I7 I7 D8 M9 |

（途中の D8 は 7-3 の「途中の回復週」として軽くする）

## 9. 確認しておきたい点

1. **腕の種目が入らない組み合わせがある。** 週2〜5日の〜60分と、週4日の60〜90分は、二頭・三頭が0種目（テンプレートで腕が60〜90分以上・90分〜に設定されているため）。重点部位で二頭・三頭を選べば入る。
2. **ハンギングレッグレイズとケーブルキックバックは代用している**（6章）。そのまま使う場合は種目マスタへの追加が必要（セルフモードの種目一覧にも出るようになる）。
3. **作成済みのテンプレート・プランは作成時点の値のまま。** 今回の方式変更や W8 の修正は、これから作るプログラムから反映される。
4. **セルフモードは以前の動的な方式のまま**（オンボーディング・ホームの提案・サイクル更新）。移す時は、既存の利用者の Day の中身が変わるため、移行の方法を別に決める。
